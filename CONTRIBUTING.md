# Contributing

This repository is a public copy of the generator from a private working repository, and a workflow refreshes it
after each change there. A change made directly in this repository would be overwritten by the next refresh.

To propose a change, open an issue that states the problem, or open a pull request as a worked proposal. The
maintainer applies an accepted change in the working repository, and the next refresh brings it here.

Every figure, rate and pattern shape in the generator names its source. A proposal that adds one should give the
publication, its date and the page.
