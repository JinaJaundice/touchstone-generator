This file lists the publications that a comment or a record in this repository cites by an identifier, such as S01. The generator takes a figure, a rate or a pattern shape from each of them. Each publication remains the work of its publisher.

The identifiers are those of the register of sources in the working repository. This list holds the entries that this copy cites, so some numbers are missing.
