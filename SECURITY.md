# Security

Report a security problem in this repository through the button "Report a vulnerability" under the Security tab of
https://github.com/JinaJaundice/touchstone-generator. Please do not open a public issue for it.

The generator runs in the browser and in Node.js and holds no account, no server and no customer data. A report is
in scope where it concerns the code in this repository or a dependency that the code loads. Only the newest commit
on main receives a fix.
